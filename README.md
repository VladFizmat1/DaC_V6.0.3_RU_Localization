Русификатор игровых текстов DaC V6 Open Beta 6.0.3

1. Полностью закройте игру.
2. Распакуйте содержимое архива непосредственно в корень папки DaC_V6_OpenBeta с заменой файлов. В корне архива сразу лежат папки data, eopData и extra.
3. Запускайте игру через установленный M2TWEOP_GUI.exe.

Архив содержит игровые тексты, их кеши и переведённые скрипты. Русификатор проверялся только на версии 6.0.3 и может работать с ошибками на других версиях.
Для установки самой игры воспользуйтесь файлами и инструкциями с дискорда разработчика: https://discord.com/invite/ymad4eY
